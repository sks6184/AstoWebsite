## 5. Attribution strength is not predictive reliability

- **What the A–D grades measure:** how well a factor is **attested** in the cited texts (A = clearly attested … D = no classical basis). They say **nothing about predictive accuracy**. That has never been measured for any of these factors, and M4's rubric is expert judgement, not empirical validation (M4-AC10).
- **Grades are provisional.** The references are unverified (§8). Seven rows say outright that a reference is "not verified" or "recalled".
- **Recommendation:**
  - If used at all, carry a grade only as an optional `attestation` note on an event guide (for example "weak classical basis; modern practice").
  - **Never** feed it into confidence or evidence strength (G-5). An A-graded factor does not make a prediction likely.
  - The answer wording stays "indicators" (G-3, G-4).

## 8. Source references that need verification

- **Cited works:** BPHS, Phaladeepika (PD), Brihat Jataka (BJ), Jataka Parijata (JP), Saravali (SV), Uttara Kalamrita (UK), Jaimini Sutras (JS), KP Readers, and modern authors (K.N. Rao, Sanjay Rath, P.V.R. Narasimha Rao).
- **None of these is in the AstroGPT vector store** (the 7 books from M2). Under G-2 the agent cannot cite them to users: a citation needs a retrieved hit. The matrix references can inform the guidance, but they never appear as citations.
- **Verification flags in the matrix itself:** 7 rows say "verse numbers not verified", "content recalled" or "not verified at verse level":
  - involuntary separation;
  - marriage timing;
  - romantic attraction;
  - childbirth timing;
  - sudden gains;
  - return to homeland;
  - meditation.
- **Edition dependence:** BPHS chapter numbering differs between editions and translations. Every "BPHS Ch.n" needs the edition stated before it is relied on.
- **Specific claims to check before any use:**
  - BPHS Ch.30 on the 2nd from UL (marriage continuity, separation);
  - BPHS Ch.33 on the 12th from Karakamsha (deity, moksha);
  - BPHS Ch.29 on A7 relative to AL (amity or enmity);
  - BPHS 7.1-8 on varga significations;
  - PD Ch.26 on transits from the Moon;
  - BPHS Ch.44 on marakas (used only for the exclusion);
  - JS 1.2-1.4 sutra numbering.
- **Recommendation:** treat every reference as UNVERIFIED until a named edition and page are checked. This is owner or researcher work, with no cost to M3.
